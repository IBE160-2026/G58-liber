## Del 2: Designinspirasjon (teknikk)
Assistenten fant ingen dokumentert dronefoto-nettside med glød-effekt; eksemplene er søkesnutter om utseende. Teknikkdelen bygger på dokumentasjon som ble lest.

### Eksempler (lav tillit)
- A. SkyView.id (konsept for flyfoto-studio): mørk modus, «cinematic animations», halvgjennomsiktig header (frosted glass) som endrer seg ved scroll. | https://kulqiz.pages.dev/en/portfolio/skyviewid/ | 2026-02 | lav. Trolig CSS backdrop-filter og scroll-lytter/IntersectionObserver (antakelse).
- B. Codrops-portefoljer (ikke drone-spesifikke): on-scroll reveal av tekst og bilder med GSAP ScrollTrigger og Lenis-jevn scroll; «minimalist Astro + GSAP build with reveals, flip transitions and subtle motion» (kun tittel). Artiklene ga 403. | https://tympanus.net/codrops/2026/02/18/joffrey-spitzer-portfolio-a-minimalist-astro-gsap-build-with-reveals-flip-transitions-and-subtle-motion/ | 2026-02-18 | lav.
- C. VOIDFLIGHT / Drone Photo Site (Framer-mal, konseptside): mørk bakgrunn, stor typografi, elektrisk lime-aksent, telemetri-linje og pulserende sikte (kun beskrivelse). | https://www.framer.com/marketplace/templates/drone-photo-site/ | lav.

### Teknikk (lest dokumentasjon, høy tillit)
- CSS scroll-driven animations: animasjon knyttes til scroll-posisjon via `animation-timeline` med `scroll()` eller `view()`, og `animation-range`. Spesifikasjonen er fortsatt kladd; `@supports`-fallback anbefales. | https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_scroll-driven_animations | MDN
- Ytelse: scroll-drevne animasjoner kan kjøre utenfor hovedtråden, `transform` anbefales fremfor `width`. Støtte oppgitt: Chrome 115, Edge 115, Firefox 159, Safari 26. Eksempel: bilder som fader inn ved synlighet og `clip-path`-reveal. Artikkelen nevner ikke prefers-reduced-motion. | https://developer.chrome.com/docs/css-ui/scroll-driven-animations | Chrome for Developers | 2023-05-05
- GSAP ScrollTrigger: `trigger`, `start`/`end`, `scrub`, `pin`; plugin, ikke i GSAP-kjernen; «highly optimized»; `gsap.matchMedia()` for responsive oppsett; `normalizeScroll()` på mobil. Nevner ikke prefers-reduced-motion. | https://gsap.com/docs/v3/Plugins/ScrollTrigger/ | GSAP
- Assistentens vurdering (ikke fra kildene): for en enkel side holder trolig CSS scroll-driven animations eller IntersectionObserver, pakket i `@media (prefers-reduced-motion: no-preference)`. Ikke bekreftet av kildene.

## Lette etter, fant ikke
- Egne dronefoto-firmaer i Bærum, Asker, Lillestrøm og Drammen med åpen pris på egen nettside (kun Finn-annonser og kataloger).
- Norsk dronefoto-firma med klart «særlig god» design; dronefoto-sider med dokumentert glød-/lyseffekt og omtale av prefers-reduced-motion.
- Anmeldelser eller meglerlogoer på små aktørers sider (bare Firmafotografen og Premani har kunde-/anbefalingsmerker).
- Farger, fonter og animasjoner var ikke synlige i WebFetch-utdragene; det trengs et visuelt blikk for å vurdere design.
